# Ambatosnake - Modernized Retro Arcade Game
---

## Key Features
---
*   **Classic Retro Snake Gameplay**: Experience the high-intensity growth and scoring of the original arcade classic.
*   **Vertical Screen-Splitting Transition**: Features a unique vertical split animation for scene transitions, providing a premium visual experience.
*   **Refined Audio Feedback**: Includes specialized sound effects for pausing and eating, with optimized background audio for immersive gameplay.
*   **Advanced Score Management**: Tracks real-time scores and maintains high-score progress across gaming sessions.
*   **Responsive Control System**: Fine-tuned keyboard controls for precise snake movement and rapid response times.
*   **Themed User Interface**: Modernized with custom visual assets, glassmorphic UI elements, and a clean, high-performance layout.

## Technologies Used
---
*   **Frontend**: HTML5, CSS3, Google Fonts
*   **Logic**: Vanilla JavaScript (Canvas API)
*   **Assets**: Custom high-resolution images and audio effects
